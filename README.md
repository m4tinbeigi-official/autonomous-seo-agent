# Hermes Autonomous SEO Agent & Information Retrieval Engineering Suite

یک ایجنت خودمختار، ماژولار و جامع برای ممیزی ۳۶۰ درجه، ترمیم خودکار ساختار اسناد (Auto-Fixer)، مدیریت گراف دانش، بهینه‌سازی موتورهای پاسخ هوش مصنوعی (GEO)، و هدایت جریان پیج‌رنک در سطح انترپرایز.
طراحی‌شده با ۱۰۰٪ پایتون استاندارد بدون نیاز به وابستگی‌های خارجی سنگین.

---

## ۱. ارکان و قابلیت‌های ایجنت خودمختار

### ۱. کانکتورهای چندمنظوره (Connectors)
- **Local Codebase / Static Site Connector:** اتصال مستقیم به پوشه خروجی بیلد یا سورس‌کد (Next.js, Astro, Nuxt, HTML, قالب‌های وردپرس).
- **Live Web Crawler Connector:** خزنده خودکار وب با کشف بازگشتی پیوندهای داخلی دامنه، کنترل عمق و رعایت سقف خزش.
- **WordPress REST API Connector:** اتصال به API وردپرس جهت دریافت نوشته‌ها و برگه‌ها و اعمال تغییرات به صورت ریموت.

### ۲. موتور ترمیم خودکار (Autonomous Auto-Fixer)
- **سنتز و تزریق هوشمند متادیسکریپشن:** استخراج گزاره‌های کلیدی متن و تولید خلاصه استاندارد ۱۲۰ تا ۱۵۰ کاراکتری.
- **استانداردسازی تایتل:** پاکسازی عناوین، حذف خط فاصله کشیده (em-dash) و تنظیم طول بهینه برای SERP.
- **تزریق آدرس قطعی و مطلق Canonical:** پیشگیری از خطای تگ‌های نسبی و داپلیکیت کانتنت.
- **استاندارد وب فارسی (VibeFarsi):** تنظیم خودکار `lang="fa-IR"` و `dir="rtl"` روی تگ سند.
- **تزریق خودکار هدینگ اصلی `<h1>`:** ارتقای موضوع صفحه به هدینگ در صورت غیبت H1.
- **مهار جهش چیدمان (CLS):** تنظیم ابعاد `width` و `height` روی تصاویر.
- **تولید متون جایگزین (`alt`):** درج خودکار متن توصیفی فارسی برای تصاویر فاقد alt.
- **تزریق گراف پیوسته Schema.org (`@graph`):** ایجاد ارتباط داده‌های ساخت‌یافته میان Organization، WebSite، WebPage و Article با ارجاعات `@id`.

### ۳. تولید خودکار دارایی‌های ریشه سرور
- ساخت خودکار نقشه سایت معتبر (`sitemap.xml`).
- تولید فایل کنترل ربات‌ها (`robots.txt`) با باز گذاشتن دسترسی خزنده‌های WRS به فونت‌های WOFF2 و فایل‌های CSS/JS.
- تولید فایل استاندارد هوش مصنوعی (`/llms.txt`) برای تصاحب جایگاه استناد در Google AI Overviews و Perplexity.

### ۴. ایمنی، رول‌بک و پیشگیری از رگرسیون
- ایجاد خودکار نسخه پشتیبان در پوشه `.seo_backup/` قبل از بازنویسی فایل‌ها.
- اعتبارسنجی با گیت CI/CD Floor-Guard برای تضمین عدم ایجاد خطاهای بحرانی پس از اصلاح.

## ۲. جعبه‌ابزار مهندسی سئو (Underlying Engineering Suite)

این مخزن علاوه بر ایجنت، شامل ۱۳ ماژول تحلیلی و ریاضیاتی مستقل است:

| ماژول | فایل اجرایی | شرح عملیاتی |
|---|---|---|
| کنسول مرکزی | `seo_master_cli.py` | رابط یکپارچه خط فرمان برای اجرای تمام آزمون‌ها و دستورات |
| ممیزی جامع ۳۶۰ درجه | `seo_audit_engine.py` | ممیزی بیش از ۲۵ فاکتور فنی، هدینگ‌ها، متاها و شبیه‌ساز پیج‌رنک |
| گراف دانش و سه‌گانه‌ها | `entity_graph_auditor.py` | استخراج سه‌گانه‌های معنایی و اعتبارسنجی گراف متصل JSON-LD |
| ممیزی هیدریشن جاوااسکریپت | `hydration_diff_checker.py` | کشف محتواها و لینک‌های پنهان از موج اول خزش گوگل (WRS) |
| نمره کسب اطلاعات (پتنت گوگل) | `information_gain_calculator.py` | سنجش آنتروپی شانون، فکت‌های عددی و حذف کلیشه‌های زرد |
| فاصله برداری و کنیبالیزیشن عصبی | `semantic_vector_auditor.py` | سنجش تشابه کسینوسی بردارها برای کشف تداخل معنایی |
| فارنزیک بودجه خزش | `server_log_analyzer.py` | تحلیل لاگ سرور با اعتبارسنجی معکوس DNS و محاسبه نرخ اتلاف |
| کشف آنومالی آماری | `causal_impact_detector.py` | تفکیک علمی افت فنی ناشی از دیپلوی از افت‌های الگوریتمی هسته گوگل |
| تولیدکننده Edge SEO | `edge_seo_generator.py` | تولید خودکار ورکر Cloudflare برای ریدایرکت‌های زیر ۲ میلی‌ثانیه |
| گیت CI/CD استقرار | `seo_ci_guard.py` | جلوگیری از مرج شدن باگ‌های سئو در پایپ‌لاین‌های استقرار |
| بهینه‌سازی برای هوش مصنوعی | `geo_ai_optimizer.py` | سنجش شاخص استناد (Citability) و تولید `/llms.txt` |
| شکارچی کلمات در آستانه جهش | `gsc_striking_distance.py` | استخراج کوئری‌های پوزیشن ۸ تا ۲۰ با پتانسیل بالای جذب کلیک |
| تزریق‌کننده فعال لینک داخلی | `active_graph_linker.py` | پیشنهاد هوشمند متن و انکرتکست برای تقویت صفحات پول‌ساز |
| مدلسازی مالی و درآمدی | `seo_business_value.py` | تبدیل بهبود سرعت و ترافیک به سود خالص و ارزش جایگزین تبلیغات |

## ۳. راهنمای اجرا

```bash
# ۱. اجرای آزمون صحت عملکرد ایجنت و تمام ماژول‌ها (Self-Tests)
python3 autonomous_seo_agent.py --test
python3 seo_master_cli.py --test

# ۲. سئوی خودکار کامل یک پوشه خروجی بیلد یا سورس‌کد
python3 autonomous_seo_agent.py \
  --target /path/to/html_or_dist \
  --domain https://mybrand.ir \
  --brand "نام برند شما"

# ۳. ارزیابی و استخراج برنامه اصلاحی بدون بازنویسی فایل‌ها (Dry Run)
python3 autonomous_seo_agent.py \
  --target /path/to/html_or_dist \
  --domain https://mybrand.ir \
  --brand "نام برند شما" \
  --dry-run

# ۴. ممیزی و خزش یک وب‌سایت آنلاین
python3 autonomous_seo_agent.py \
  --target https://example.com \
  --domain https://example.com \
  --brand "برند نمونه" \
  --max-pages 15

# ۵. بررسی سلامت سئو در گیت CI/CD
python3 seo_master_cli.py ci-guard /path/to/dist
```
